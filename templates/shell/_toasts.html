{% comment %} The result of an action, as a toast rather than a box pushed into the page. Which ones stay until closed ---------------------------- Successes and notes leave on their own after a few seconds. Errors and warnings do not: something went wrong and the reader has to see it. Neither does anything tagged `sticky` — which is what carries a one-time temporary password. An auto-dismissing toast would take the only copy of that password away while HR glanced at the new starter, and nobody could sign in. Why the script is inline, right here ------------------------------------ The toasts are hidden until this script opens them. If the script came from a separate file and that request failed on a weak connection, they would stay hidden forever. Inline, it arrives with the page or not at all, and it runs before the browser paints the stack, so there is no flash. If it never runs, [data-armed] is never set and every message stays plainly visible in the page, exactly as before. {% endcomment %} {% if messages %}
